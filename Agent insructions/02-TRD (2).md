# 02 — Technical Requirements Document (TRD)

## Frontend
Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui components, Recharts (score history), Lucide React (icons)

## Backend
Next.js API routes — no separate server. Sequential module execution (not parallel) with a real-time progress stream to the client.

## Database
Firebase Firestore — projects, validation runs, score history

## Auth
Firebase Auth — Google sign-in only for v1 (fastest to ship, no password-reset flows to build)

## Hosting
Anti-Gravity (standard Next.js build target) — frontend + API routes in one deployment

## Third-Party APIs & Services
| Service | Purpose | Tier |
|---|---|---|
| OpenAI GPT-4o / GPT-4o-mini | Reasoning, copy generation, qualitative review (mini for cheap/simple calls, 4o for synthesis) | Paid, cost-controlled |
| GitHub REST API | Read-only repo metadata (README, LICENSE, package.json, commit history, issue count) | Free tier |
| Lighthouse (via Puppeteer / lighthouse-core, or Lighthouse CI) | Performance, Accessibility, SEO, Best Practices scores | Free |
| Puppeteer / Cheerio | Landing page scraping for structure + copy | Free |
| pdf-parse or pdfjs-dist | Extract text from pitch deck PDF | Free |
| jspdf + html2canvas | Branded PDF report export | Free |
| Firebase Firestore + Auth | Data storage, Google sign-in | Free tier (Spark) sufficient for MVP |

## Key Libraries
- `zod` — input validation for all submitted URLs/files
- `react-query` (or SWR) — client-side data fetching/caching for dashboard
- `recharts` — score history line chart
- `lucide-react` — icon set

## Hard Constraints
- Must run as a single Next.js deployment — no separate backend service
- Must degrade gracefully — one module failing (e.g., scraping blocked) never crashes the pipeline
- LLM must never invent numeric scores from nothing — every score traces back to a deterministic signal (Lighthouse number, presence/absence of a file, word count, etc.) with LLM providing the qualitative layer on top
- No GitHub write scope, ever, in any version shipped this hackathon
