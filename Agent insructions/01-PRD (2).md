# 01 — Product Requirements Document (PRD)

## App Name
**Forge AI**

## Tagline
Launch Better. Build Smarter. Validate Faster.

## Problem
Early-stage products — startups, hackathon projects, indie apps — almost always launch or get pitched without structured expert feedback. Founders and student teams rarely have access to a real engineer, designer, security reviewer, and business advisor before their demo or launch day. Critical gaps (weak README, bad CTA, missing accessibility basics, unclear value prop) go unnoticed until a judge, investor, or user finds them first.

## Target User
Early-stage founders, hackathon teams, and indie hackers who have a live URL and/or GitHub repo and need a fast, structured "is this ready to show people" check — without waiting days for a human reviewer. Secondary user: accelerator/incubator staff screening a cohort's projects before demo day.

## Core Value Proposition
Instead of asking one generic AI assistant for feedback, Forge AI runs your product through six specialized, rubric-based analysis modules — combining real deterministic checks (Lighthouse, GitHub metadata, page structure) with domain-specific reasoning — and returns one unified Launch Readiness Report with concrete, copy-pasteable fixes.

## Core Features (Must Have)
- Project creation: submit Website URL, GitHub Repo URL, Pitch Deck PDF (optional), Screenshots (optional)
- 6 analysis modules: Product Understanding, Engineering Analysis, UX Validation, Performance Audit, Business Review, Launch Planner
- Real-time progress tracker showing which module is currently running
- Dashboard: overall Launch Readiness Score (0–100), 6 category scores, prioritized issue list (Critical/High/Medium/Low)
- "Copy Fix" button per issue — generates a concrete improved version (copy, code snippet, meta tag, etc.)
- Re-validate a project and see score history over time (line chart)
- Export report as PDF and Markdown
- Google sign-in (Firebase Auth)

## Nice to Have (v2)
- GitHub OAuth with automatic PR creation for fixes (explicitly out of scope for v1)
- Slack/email notifications when a re-validation completes
- Team/multi-user projects with shared history
- Custom rubric weighting per user
- Public shareable report links

## Out of Scope (v1)
- No chat interface — this is not a chatbot
- No GitHub write access, PR creation, or automatic commits
- No vector databases, RAG, or retrieval pipelines
- No payment integration — free tier only
- No deep static-code / vulnerability scanning (metadata-level GitHub checks only)
- No microservices or complex infra — single Next.js deployment

## User Stories
- As a founder, I want to paste my landing page URL and repo link so I can see if my product is ready to launch.
- As a hackathon team, I want a fast, visually impressive readiness report I can show judges live.
- As a returning user, I want to re-validate my project and see whether my score improved since last time.
- As a user with an unpolished README, I want a one-click "Copy Fix" so I don't have to write documentation from scratch.
- As a non-technical founder, I want my pitch deck reviewed alongside my landing page so business and product feedback are consistent.

## Success Metrics
- End-to-end validation run completes in under 90 seconds for a typical project
- At least 5 of 6 modules return real (non-fallback) data on a standard public repo + live URL
- A first-time user reaches the dashboard and understands their top 3 issues without explanation
- Judges/demo viewers verbally react to the "Copy Fix" moment within the first 60 seconds of a live demo
